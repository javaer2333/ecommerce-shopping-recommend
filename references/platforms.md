# 平台采集手册

按「先列表、后详情、再交叉核对」的顺序采集。所有数值必须记录来源 URL 和采集时间；页面结构会变，优先认文字标签，不依赖固定 CSS class。

## 通用规则

1. **短链先还原**：分享链接常是 `m.tb.cn`、`u.jd.com`、`v.douyin.com`、`p.pinduoduo.com` 等短链。先在浏览器打开，等跳转完成，读取地址栏 canonical URL 和商品标题。
2. **认字段不认位置**：用页面可见文字定位「好评率」「已售」「已拼」「评价」等标签，再取相邻数值。
3. **到手价口径**：商品价 − 优惠券 − 满减 + 运费；会员价、百亿补贴、限时秒杀单独标注。不要拿「划线价」当成交价。
4. **销量口径**：平台展示的是累计或近 30 天，口径不同不可直接横比；报告注明「平台口径」。
5. **评价看三条**：好评率/评分、评价总数、差评关键词。只有好评率没有评价量的，可信度降权。
6. **一页一停**：详情页之间停 3–5 秒；单平台 ≤8 个详情页；不滚动加载超过 3 屏。
7. **遇登录/验证码**：请用户手动完成，继续用同一会话；不换号、不绕验证。

## 淘宝 / 天猫

**入口**
- 搜索：`https://s.taobao.com/search?q=<关键词>`；天猫列表：`https://list.tmall.com/search_product.htm?q=<关键词>`
- 商品：`https://item.taobao.com/item.htm?id=<id>`；天猫：`https://detail.tmall.com/item.htm?id=<id>`
- 分享短链：`m.tb.cn`、`e.tb.cn`；闲鱼分享也可能走 `m.tb.cn`，打开后看域名再判断。

**列表页读什么**
- 标题、到手价/券后价、月销/已售、店铺名、发货地、标签（天猫、旗舰店、百亿补贴、包邮）。
- 排序：先「综合」再「销量」；价格带用筛选器卡住，避免跨档比较。
- 广告位（「广告」/「HOT」）不算自然结果，记录时标注。

**详情页读什么**
- 完整标题、SKU（颜色/容量/套装）、促销价与条件、店铺评分（描述/服务/物流）、评价数、追评、问大家。
- 淘宝很多类目**不直接展示好评率**：用「评分（4.6–5.0）+ 评价数 + 差评关键词 + 追评」推算，并标「推算」。天猫部分商品页有「好评率」标签。
- 店铺类型：天猫旗舰店 > 天猫专卖/专营 > 淘宝企业店 > 个人店；品牌授权信息在「资质」里。
- 服务：七天无理由、运费险、破损包赔、价保。

**坑**
- 低价 SKU 引流：标题写「耳机」，最低价 SKU 是「耳机套」；必须点开对应 SKU 核对。
- 「原价」虚高：只看券后到手价，记录用券条件。
- 预售/定金：到手价要加定金，标注发货期。
- 同款不同质：同一型号有「官方标配/套装/翻新」，拆开比较。

## 京东

**入口**
- 搜索：`https://search.jd.com/Search?keyword=<关键词>&enc=utf-8`
- 商品：`https://item.jd.com/<sku>.html`
- 分享短链：`u.jd.com`、`3.cn`。

**列表页读什么**
- 价格、好评率（常直接显示，如「97%」）、评价数、自营/POP 标、京东物流、次日达、百亿补贴。
- 排序：综合 → 销量 → 价格；勾选「自营」「京东物流」「仅看有货」。

**详情页读什么**
- 好评率、评价总数、追评、差评标签（如「噪音大」「续航短」）、商品评分、店铺评分。
- 自营 vs 旗舰店 vs 专营店：自营售后由京东兜底；POP 看店铺评分和发货时效。
- 服务：价保、只换不修、上门取件、以旧换新。
- 食品：详情页常见营养成分表、配料表、保质期；没有就看包装图放大读取。

**坑**
- 自营与第三方混排：同一商品链接可能切店铺，确认「由京东发货并提供售后」。
- 百亿补贴限购/需实名，价格可能与页面价不同。
- 秒杀价随时恢复，报告写「采集时价格」。
- 京东国际/全球购含税，到手价要加税。

## 拼多多

**入口**
- 搜索：`https://mobile.yangkeduo.com/search_result.html?search_key=<关键词>`
- 分享短链：`p.pinduoduo.com`、`mobile.yangkeduo.com/goods.html?goods_id=<id>`
- 网页端常引导下载 App；优先用移动端页面，必要时请用户在当前浏览器打开。

**列表页读什么**
- 已拼/已售件数、价格、百亿补贴标、品牌黑标、店铺名、发货地。
- 排序：综合 → 销量；先看「百亿补贴」「品牌」频道，再看普通店。

**详情页读什么**
- 到手价、已拼件数、评价数、好评率（部分展示）、店铺资质、退货包运费、仅退款。
- 食品看生产日期/保质期/SC；低价食品警惕临期、散装分装。
- 店铺：品牌旗舰/黑标 > 专营 > 普通个人店；点「店铺」看营业执照与评分。

**坑**
- 低价引流 SKU：最低价常是「配件/试用装/单件」，点开确认规格。
- 「百亿补贴」也可能混非补贴 SKU，认标签和价格。
- 评价里「返现好评」多，重点看追评和差评图。
- 部分商品不支持七天无理由，详情页确认。

## 抖音电商

**入口**
- 抖音搜索：`https://www.douyin.com/search/<关键词>?type=general`，结果里切「商品/商城」。
- 商品页：`https://haohuo.jinritemai.com/views/product/item2?id=<id>`
- 分享短链：`v.douyin.com`；直播间/短视频挂车商品需打开对应视频或直播回放。

**列表页读什么**
- 已售件数、价格、店铺名、达人/直播间标签、口碑分、发货地。
- 区分：商城自然搜索、达人带货、直播间专属价；三者价格可能不同。

**详情页读什么**
- 已售、评价数、好评率/口碑分、店铺评分、售后政策（七天无理由、运费险）、发货时效。
- 食品看营养成分表、生产许可、保质期；达人视频里的卖点不能替代详情页。
- 店铺：品牌旗舰店 > 专营店 > 个体店；看「店铺体验分」。

**坑**
- 直播间话术与详情页不一致，以详情页和订单页为准。
- 「原价」对比常夸张，记录实际支付价。
- 部分商品售后入口深，确认是否支持七天无理由。
- 短视频/直播可能已下架，商品页失效时换搜索关键词。

## 闲鱼

**入口**
- 搜索：`https://www.goofish.com/search?q=<关键词>`
- 商品：`https://www.goofish.com/item?id=<id>`
- 分享短链：`m.tb.cn` 可能跳闲鱼；以最终域名为准。

**列表页读什么**
- 价格、成色（全新/99新/95新等）、卖家昵称、信用（芝麻信用/实人认证）、发货地、是否支持验货宝。
- 排序：综合 → 最新/距离；优先「验货宝」「信用极好」。

**详情页读什么**
- 成色描述、入手渠道、购买时间、保修/发票、瑕疵图、卖家评价（历史）、芝麻信用、实人认证。
- 二手没有「好评率」概念：用卖家历史评价、信用分、回复专业度、是否愿意走验货宝综合判断。
- 交易方式：闲鱼担保交易 > 验货宝 > 面交；拒绝脱离平台转账。

**坑**
- 翻新/组装机、暗病、维修史：要求提供序列号、购买凭证、维修记录。
- 「全新未拆」低价：核对渠道、发票、保修；低于市场价 30% 直接排除。
- 面交风险：约在公共场所，当场验机；不先付定金。
- 卖家信用 <650 或差评多：排除；新号卖高价数码：降权或排除。

## 跨平台核对清单

| 核对项 | 做法 |
| --- | --- |
| 是否同款 | 品牌 + 型号 + 规格 + 版本（国行/海外/翻新）四项一致 |
| 价格是否同口径 | 含券、含税、含运费、是否会员价、是否二手 |
| 销量是否同口径 | 累计/月销/已拼，报告注明，不直接排名 |
| 好评率是否同源 | 平台展示 vs 推算，推算要标注 |
| 售后是否可比 | 七天无理由、运费险、质保时长、上门/寄修 |
| 食品是否同规格 | 每 100g 换算，注意「每份」与「每袋」 |
